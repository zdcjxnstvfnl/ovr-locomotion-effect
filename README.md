## 🕹️ Overview

OVR Locomotion Effect applies a configurable FOV reduction vignette during artificial locomotion in any SteamVR game, reducing motion sickness significantly.

Whether you're a newcomer or a veteran, OVR Locomotion Effect provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Comfort Vignette** | Narrows FOV during movement to reduce simulator sickness |
| **Per-Game Config** | Separate vignette settings saved for each SteamVR title |
| **Speed Scaling** | Vignette intensity scales with in-game movement speed |
| **Instant Toggle** | Hotkey to enable or disable the effect without leaving VR |
